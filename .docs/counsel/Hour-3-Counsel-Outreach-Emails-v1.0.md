## Tactics

- **Send Corporate/Tax first**, then IP 24 hours later, then Securities 24 hours after that. This spaces the response calendar.
- **Don't send Friday afternoon or Monday before noon** — both are email-death zones. Target Tuesday–Thursday 10am–3pm their local time.
- **If no response after 5 business days**, send a one-line bump: `Hi {name}, following up on the below — happy to provide any additional detail before a call. Thanks.`
- **Log everything** — firm, partner, date sent, response received, next step — in a simple sheet so you don't double-send or lose track across three parallel engagements.
- **Mutual NDA template** — have one ready before first positive response. If you don't, tell me and I'll draft one.

## After positive responses

1. Reply confirming the call time and propose mutual NDA execution ahead of the call.
2. Execute NDA (DocuSign or similar — same day if possible).
3. Send Pack v2.0 + IP Inventory v1.1 + relevant scope excerpts under NDA 24 hours before the call.
4. Run the call. Core agenda: their experience with analogous work, their team, fee structure (prefer fixed-fee by workstream), timeline fit, conflicts.
5. Ask each firm for a written scoping proposal with fee structure. Target 3 proposals per category, select 1, engage.
